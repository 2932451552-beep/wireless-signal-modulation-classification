# 第四课：1D CNN与前向传播

## 1. CNN在这个项目里做什么

输入是一批I/Q时间序列：

```text
(batch, 2, length)
```

1D CNN使用小型卷积核沿时间方向移动，逐段观察相邻采样点，学习不同调制方式可能具有的局部变化模式。

模型不会直接读取“BPSK”或“QPSK”文字。它看到的是I/Q数字，最终学习哪些数字模式更接近某个类别。

## 2. 当前网络结构

```text
I/Q输入：2个通道
→ Conv1d：生成32个特征通道
→ ReLU：保留正向激活
→ MaxPool1d：缩短时间长度
→ Conv1d：生成64个更高层特征通道
→ ReLU
→ AdaptiveAvgPool1d：每个特征通道汇总成一个值
→ Linear：输出每个调制类别的分数
```

卷积产生的32和64个通道不是新的无线信号，而是神经网络学习到的特征图。

## 3. 什么是前向传播

信号从输入依次经过各层并得到输出分数，这个过程叫前向传播：

```text
I/Q批次 → CNN → 每个类别的分数
```

如果输入形状是`(8, 2, 128)`，类别数是11，输出形状就是：

```text
(8, 11)
```

代表8条信号，每条信号对应11个类别分数。

## 4. Logits不是概率

模型输出的原始类别分数叫logits。它们可以是正数或负数，也不要求加起来等于1。

训练时将logits和正确标签直接交给交叉熵损失，不需要提前手动执行Softmax。需要向用户展示概率时，才在推理阶段使用Softmax。

## 5. 损失和反向传播

交叉熵损失衡量模型输出和正确类别之间的差距。损失计算后执行反向传播，PyTorch会计算每个参数应该向哪个方向调整。

当前阶段只验证：

1. 输入可以通过网络；
2. 输出形状正确；
3. 损失是有限数字；
4. 反向传播能够产生梯度。

我们还没有创建优化器，也没有反复更新参数，所以现在的模型仍然是随机初始化模型，不能报告准确率。

## 6. 当前模型为什么保持简单

第一版模型只有11,499个可训练参数，目的是先验证数据和训练闭环。复杂模型不一定更准确，而且会增加排错和解释成本。只有完成基线评估后，才会进行一次受控改进实验。
