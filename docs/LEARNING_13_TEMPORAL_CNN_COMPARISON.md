# 学习 13：保留时序特征的受控模型改进

## 这次只改变了什么

旧版SimpleCNN在第二层卷积后使用全局平均池化，把整段信号压缩为每个通道一个平均值。它很轻量，但可能丢失不同采样位置之间的排列和局部变化。

新版TemporalCNN把128点I/Q信号逐步提取为8段时序特征，再交给分类器。数据集、70%/15%/15%划分、随机种子、学习率、批大小、优化器、训练轮数上限和评估方法全部不变。因此本次对照主要回答：保留更多时序位置是否比过早全局平均更有效。

## 工程问题与处理

最初使用自适应平均池化保留8段特征，但PyTorch在当前CUDA环境中不支持这个算子的确定性反向传播。可复现性保护在第一轮训练前终止了实验，没有产生模型检查点。

没有关闭确定性保护，而是利用RadioML固定128点输入，将该算子换成固定窗口平均池化。修改后先完成GPU反向传播小验证和73项自动化测试，再重新运行完整实验。

## 公平对照结果

| 指标 | SimpleCNN | TemporalCNN | 变化 |
| --- | ---: | ---: | ---: |
| Validation Accuracy | 40.89% | 56.35% | +15.46个百分点 |
| Validation Macro F1 | 38.20% | 56.23% | +18.03个百分点 |
| 最佳轮次 | 20 | 13 | - |
| 可训练参数 | 11,499 | 224,587 | 模型容量增加 |
| 训练与验证耗时 | 约63秒 | 约71秒 | 约增加8秒 |

TemporalCNN在第13轮达到最低验证损失，随后连续4轮没有进一步改善，因此在第17轮触发早停，并恢复第13轮参数。最终指标不是最后一轮的结果。

## SNR现象

- -20 dB：Accuracy约9.15%，仍接近11分类随机水平；
- -6 dB：Accuracy约54.12%；
- 0 dB：Accuracy约79.82%；
- 4 dB：Accuracy约82.97%；
- 14 dB和18 dB：Accuracy约82.79%。

这说明新模型在信号较清晰时已经能提取较稳定的调制特征，但极低SNR下仍受到噪声主导。

![SimpleCNN与TemporalCNN的验证集SNR曲线](images/phase13/validation_accuracy_by_snr.svg)

## 不能忽略的类别问题

所有类别的F1都比SimpleCNN提高，但QAM16的Recall仍只有约4.07%，其中大量样本被预测为QAM64。WBFM也经常与AM-DSB混淆。总体准确率提高不代表每一类都已经解决，因此仍要同时查看Macro F1、分类别Recall和混淆矩阵。

![TemporalCNN验证集混淆矩阵](images/phase13/temporal_cnn_confusion_matrix.svg)

## 当前结论

保留粗粒度时序位置是有效改进，TemporalCNN可以作为最终候选模型。这个结论只基于验证集，测试集仍未使用。

下一步应先冻结候选模型和最终评估协议，生成混淆矩阵及SNR曲线。只有确认后续不再依据测试结果调参，才对封存测试集进行一次最终验收。
