# 学习 08：从220个分组到训练批次

## 原始字典为什么不能直接交给模型

RadioML文件是一个字典，键是 `(调制方式, SNR)`，值是一组1000条信号。模型训练需要按编号逐条读取信号，因此项目增加了一个Dataset适配层：它把“第几条样本”映射到对应分组和分组内部位置。

适配器不会先把22万条信号重新拼接复制一遍。它保留原来的220个NumPy数组，只建立少量索引和标签数组；DataLoader取到某个批次时，才把需要的信号组织成Tensor批次。

## 类别编号

神经网络不能直接把 `BPSK`、`QPSK` 等字符串作为答案，因此项目建立稳定映射：

```text
调制方式字符串 → 0到10之间的整数标签
```

模型输出11个logits，正确标签就是其中一个整数编号。

## 为什么按“调制方式＋SNR”分层划分

如果只随机切分，不检查组合比例，某些低SNR或某些调制方式可能在训练集和测试集中分布不一致。项目对每个调制/SNR分组分别按70%/15%/15%划分，再合并为：

- 训练集：154,000条；
- 验证集：33,000条；
- 测试集：33,000条。

三部分索引互不重叠，每条信号只出现一次。

## 当前阶段边界

本阶段只验证真实数据能被Dataset和DataLoader正确读取，还没有用RadioML更新模型参数，也没有产生正式准确率。
