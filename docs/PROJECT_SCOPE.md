# V1 项目范围

## 问题定义

输入一段包含 I（同相）和 Q（正交）两个通道的无线信号序列，模型输出该信号所属的调制类别。数据中的 SNR 标签用于分析噪声强弱对识别性能的影响，不作为模型正确率的替代指标。

## 第一版实验原则

1. 先完成数据检查和简单基线，再训练 1D CNN。
2. 训练、验证、测试数据严格分离，固定随机种子并记录配置。
3. 同时报告整体指标、分类别指标和按 SNR 分组的指标。
4. 只改变一个主要变量进行改进实验，避免无法判断效果来源。
5. 合成数据上的结果不等同于真实无线环境中的效果。

## 阶段顺序

1. 环境与数据审计。
2. I/Q、调制、SNR 与数据格式学习。
3. 数据加载、划分和可视化。
4. 简单基线与 1D CNN 训练。
5. 混淆矩阵、SNR 曲线和错误分析。
6. 单变量改进实验。
7. 测试、README、复现说明和 GitHub 发布。
