# 学习 09：为什么先做冒烟训练

## 冒烟测试不是正式实验

冒烟训练的目标是尽快确认真实数据、GPU、模型、损失、优化器、验证和模型保存能够连成闭环。它只使用高SNR条件下的一小部分样本，并只训练少量轮次，因此不能代表完整RadioML测试效果。

本阶段覆盖11个类别和10、12、14、16、18 dB五个较高SNR档位：

- 训练：每个类别/SNR组合100条，共5500条；
- 验证：每个组合30条，共1650条；
- 测试集：完全不使用。

## 为什么先选择高SNR

高SNR信号中的噪声较弱，适合先检查模型能否从真实I/Q信号中学习到基础差异。如果高SNR小样本都完全无法学习，应先检查数据映射、模型或训练参数，而不是直接消耗时间跑完整训练。

## 结果应该怎么看

- 能正常完成前向、反向和保存，说明工程链路成立。
- 损失下降，说明优化器正在找到更合适的参数。
- 小子集准确率只用于诊断，不写入简历，也不与论文结果比较。
- 正式结果必须使用完整训练集、预先固定的验证方案和从未参与调参的测试集。
