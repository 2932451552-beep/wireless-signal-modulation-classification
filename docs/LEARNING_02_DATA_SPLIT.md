# 第二课：训练集、验证集、测试集和数据泄漏

## 1. 三个集合分别做什么

- 训练集：模型反复查看，用于学习神经网络参数。
- 验证集：开发过程中查看，用于选择网络结构、学习率、训练轮数等方案。
- 测试集：方案完全确定后才打开，用于最终独立验收。

记忆：训练集用来学，验证集用来改，测试集最后才打开。

如果根据测试集结果不断修改模型，测试集实际上就变成了验证集，最终数字会过于乐观。

## 2. 为什么要按“调制方式 + SNR”分层

调制方式是模型要预测的类别，SNR是输入信号的噪声条件。二者组合形成一个分层，例如：

```text
(BPSK, -10 dB)
(BPSK,  10 dB)
(QPSK, -10 dB)
(QPSK,  10 dB)
```

在每个分层内部按照相同比例划分，可以让训练、验证和测试集合都覆盖相同的类别和噪声范围。否则某个集合可能包含过多容易的高SNR信号，另一个集合包含过多困难的低SNR信号，指标就不容易比较。

## 3. 什么是数据泄漏

同一条样本只能出现在一个集合中。如果同一条信号同时进入训练集和测试集，模型可能只是记住了它，测试准确率就不能代表处理新信号的能力。

本项目的完整性检查保证：

1. 所有样本都被分配；
2. 没有样本被遗漏；
3. 没有样本重复进入两个集合；
4. 所有索引都在合法范围内。

## 4. 为什么固定随机种子

划分前需要随机打乱数据。固定随机种子可以让同一份数据每次得到相同划分，使不同模型之间的实验更公平，也让其他人能够复现实验。

固定随机种子不代表数据不再随机，而是代表这次随机结果能够再次生成。

## 5. 当前划分策略

真实数据计划在每个“调制方式 + SNR”分层中使用：

```text
训练集：70%
验证集：15%
测试集：15%
```

本课演示为了方便检查，使用60%/20%/20%的小型模拟元数据。演示只验证划分逻辑，不代表最终实验数据。
