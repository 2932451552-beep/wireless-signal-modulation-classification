# 第一课：I/Q、调制与 SNR

## 1. 一条无线信号在代码里是什么

接收机观察到的信号通常用复数表示：

```text
x = I + jQ
```

- `I` 是同相分量，可以理解为复平面的横坐标。
- `Q` 是正交分量，可以理解为复平面的纵坐标。
- 一条长度为 `L` 的复数信号，交给神经网络前通常整理为 `(2, L)`：第一行是 I，第二行是 Q。
- 多条样本组成一个批次后，常见形状为 `(N, 2, L)`，其中 `N` 是样本数量。

I/Q不是两个独立答案，而是同一个复信号的两部分。

## 2. 什么是调制识别

调制是把待传输的信息映射到载波信号上的方法。不同调制方式会形成不同的幅度、相位或频率变化规律。

- BPSK 每个符号有两种状态，本课使用 `+1` 和 `-1`。
- QPSK 每个符号有四种状态，对应复平面上的四个点。

自动调制识别的任务是：给模型一小段未知 I/Q 信号，让它判断这段信号属于哪一种调制方式。因此它本质上是一个多分类问题。

## 3. 什么是 SNR

SNR 是信号功率和噪声功率的比值，通常以 dB 表示：

```text
SNR(dB) = 10 × log10(信号功率 / 噪声功率)
```

- SNR 高：信号比噪声强，波形更容易辨认。
- SNR 为 0 dB：信号功率和噪声功率大致相等。
- SNR 为负：噪声功率比信号功率更强，识别更困难。

SNR不是准确率。它描述输入信号的噪声条件；准确率描述模型答对了多少样本。

## 4. 本课代码做了什么

1. 把随机比特映射成 BPSK 或 QPSK 复数符号。
2. 使用 AWGN（加性白高斯噪声）构造不同 SNR 的信号。
3. 在复数序列和 `(2, L)` 的 I/Q 数组之间转换。
4. 根据干净信号和加噪信号估算实际 SNR。

AWGN是一个基础噪声模型。它适合帮助理解和测试代码，但不能覆盖真实无线环境中的衰落、频偏、多径和硬件误差。

## 5. 为什么后续使用 1D CNN

I/Q样本是沿时间排列的一维序列。1D CNN的卷积核会沿时间方向滑动，尝试学习相邻采样点之间的局部模式。它不是直接背诵某一个数字，而是逐步学习不同调制方式的波形特征。

## 6. 数据集边界

计划使用的 RadioML 2016.10A 是 GNU Radio 生成的合成数据，包含11种调制方式和不同SNR。DeepSig明确把它定位为早期、历史和教育用途数据，并提示存在已知问题，因此后续实验结果不能直接代表真实空口环境。
