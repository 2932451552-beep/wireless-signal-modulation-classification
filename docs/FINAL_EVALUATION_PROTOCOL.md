# 最终测试集启封协议

## 目的

本协议在读取测试集指标之前冻结，用于防止根据测试结果反复调整模型，从而造成测试集信息泄漏。

## 已冻结的候选模型

- 模型：`TemporalCNN1D`
- 输入：固定`(2, 128)` I/Q序列
- 分类：11种调制方式
- 随机种子：`20260812`
- 训练集：154,000条
- 验证集：33,000条
- 封存测试集：33,000条
- 最佳轮次：13
- 选择依据：最低验证损失
- 模型检查点SHA-256：`424bd247b767d0ab23c7d2217445dea62d351d9cc54ec1fe0f9bacbb770349b3`
- 数据集SHA-256：`b29ccc25b00d0718cd3b70ffa9158662ec83f6d9b63ffd845c7bcbe3b3096e8c`

## 最终评估只允许执行什么

1. 从检查点加载第13轮模型参数；
2. 按原始分层划分创建测试集DataLoader，禁止重新划分；
3. 只进行推理，不计算梯度、不更新参数；
4. 输出一次Accuracy、Macro Precision/Recall/F1、分类别指标、混淆矩阵和按SNR准确率；
5. 保存机器环境、样本数、耗时、检查点哈希和结果JSON；
6. 生成最终图表并如实记录结果。

## 测试结果出来后禁止什么

- 不根据测试准确率修改模型或超参数后重新报告同一测试集；
- 不删除表现差的类别或SNR区间；
- 不把验证集和测试集成绩混写；
- 不把单次数据集结果描述成真实无线环境的普遍性能；
- 不隐藏失败或低于预期的结果。

若测试脚本因纯工程问题失败，例如文件路径错误或结果写入失败，可以修复后重跑，但必须确认失败运行没有用于选择模型，也没有泄露可供调参的测试指标，并在记录中说明。
