# 学习 06：为什么保存最佳模型并提前停止

## 最后一轮不一定是最好的一轮

训练轮数增加时，训练集损失通常继续下降，但验证集损失可能先下降再上升。这说明模型越来越会做训练题，却开始失去处理新数据的能力，也就是过拟合。

所以项目按照验证集损失选择最佳轮次，而不是默认保留最后一轮。

## Checkpoint 保存什么

当前检查点保存：

- 最佳轮次编号；
- 验证损失和准确率；
- 模型参数；
- 优化器状态。

模型参数用于恢复预测能力，优化器状态用于需要时继续训练。

## Early stopping 怎么工作

`patience=2` 表示：验证损失连续两轮没有取得足够改善，就停止后续训练。它的目的不是让模型跑得更快，而是减少没有收益的训练并降低过拟合风险。

## 三个容易混淆的概念

- 最佳训练准确率不等于最佳模型，应优先观察验证集。
- 验证集用于选择轮次和参数，不能反复充当最终测试集。
- 测试集应在方案确定后用于最终验收，不能拿测试结果反向调参。
