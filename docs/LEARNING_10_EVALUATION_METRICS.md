# 学习 10：为什么不能只看Accuracy

## Accuracy

准确率是“预测正确的样本数 ÷ 总样本数”。它直观，但无法说明模型具体把哪种调制方式认错成了哪一种。

## Precision、Recall和F1

对某一个类别来说：

- Precision：模型说“这是该类别”时，有多少是真的；
- Recall：真实属于该类别的信号，有多少被找出来；
- F1：Precision和Recall的调和平均，用来平衡二者。

宏平均先分别计算11个类别，再取平均，因此每个类别权重相同，不会让样本多的类别掩盖样本少的类别。

## 混淆矩阵

本项目的矩阵：行表示真实类别，列表示预测类别。对角线是正确分类，非对角线能显示具体混淆关系，例如QAM16是否经常被识别成QAM64。

## 按SNR准确率

总准确率会把不同噪声条件混在一起。按SNR统计能显示模型从低信噪比到高信噪比的性能变化，这是无线信号分类项目的重要评估维度。

## 测试纪律

评估代码可以先用验证集检查，但测试集只在模型结构和参数确定后使用。不能根据测试集的混淆矩阵继续调参，否则最终成绩会带有测试集信息泄漏。

## 为什么同一个实验还要控制随机性

固定随机种子只解决随机初始化和数据顺序；GPU某些高性能算法仍可能产生极小差异。项目同时固定Python、NumPy、PyTorch和DataLoader随机源，并启用确定性GPU算法。这样牺牲少量速度，换取更容易复现和比较的实验结果。
