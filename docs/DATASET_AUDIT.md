# RadioML 2016.10A 数据集审计

## 结论

RadioML 2016.10A 可以作为本项目的教学和作品集基线，但不能被描述成真实空口生产数据。数据本体不提交 Git，下载、许可、完整性和旧 Pickle 风险必须单独记录。

## 官方来源与限制

- 官方介绍：https://www.deepsig.ai/datasets/
- 官方生成代码：https://github.com/radioML/dataset/blob/master/generate_RML2016.10a.py
- 许可：CC BY-NC-SA 4.0
- 性质：GNU Radio 生成的早期合成数据。
- 官方提示：数据用于历史和教育用途，存在已知问题，当前不用于 DeepSig 产品。
- 下载限制：官方当前要求用户提供姓名、单位和邮箱后确认下载，项目不会自动提交或伪造这些信息。

CC BY-NC-SA 4.0 要求署名、非商业使用和相同方式共享衍生材料。代码仓库的许可证不会改变数据集本身的许可证；仓库只保留下载说明，不重新分发数据文件。

## 从官方生成代码得到的结构

官方脚本定义：

- 11 种调制方式；
- SNR 从 -20 dB 到 18 dB，每 2 dB 一个档位，共 20 档；
- 每个“调制方式 + SNR”组合 1000 条样本；
- 每条样本形状为 `(2, 128)`；
- 数据类型为 `float32`。

由此推导：

```text
总样本数 = 11 × 20 × 1000 = 220,000
纯数组载荷 = 220,000 × 2 × 128 × 4 bytes
             = 225,280,000 bytes
             ≈ 214.84 MiB
```

本机已从 DeepSig 官方渠道取得数据，并于 2026-08-18 再次完成只读核验：

- 压缩包大小：228,491,318 字节；
- 压缩包 SHA-256：`7a1603dd61e557f45b6e113dc0c59be02a14509b77856c31bbb324a993f7974c`；
- 归档成员：`RML2016.10a_dict.pkl`、`LICENSE.TXT`；
- Pickle 大小：640,919,653 字节；
- Pickle SHA-256：`b29ccc25b00d0718cd3b70ffa9158662ec83f6d9b63ffd845c7bcbe3b3096e8c`。

考虑解压、格式转换、训练划分和临时数组，重新准备数据时仍建议至少预留 3–5 GB 工作空间。

## 下载后的安全流程

1. 只接受官方 DeepSig 下载，不使用无法核实的网盘或镜像。
2. 下载到 Git 忽略的本地数据目录。
3. 记录文件大小和 SHA-256，后续重复实验使用同一文件。
4. 在解压前检查 tar 成员，拒绝绝对路径、`..` 路径穿越、符号链接和异常文件类型。
5. 官方文件使用旧 Pickle 格式。Pickle 可能执行代码，因此不能对来源不明的文件直接调用 `pickle.load`。
6. 在官方来源和归档结构确认后进行一次受控转换，立即校验键、形状、类型、有限值和类别范围。
7. 转换为不需要 Pickle 的数组格式，后续训练不再重复加载原始 Pickle。

当前 `scripts/audit_dataset_archive.py` 只读取归档结构、大小和 SHA-256，不解压，也不加载 Pickle。

## 数据划分方案

第一版固定随机种子，并在每个“调制方式 + SNR”组合内部进行分层划分：

```text
训练集：70% = 每组 700 条，共 154,000 条
验证集：15% = 每组 150 条，共 33,000 条
测试集：15% = 每组 150 条，共 33,000 条
```

这样每种调制方式、每个 SNR 在三个集合中都有相同占比。测试集只用于最终评估，不能用于选择模型参数。

原始数据没有提供可用于分组的发射序列 ID，因此无法完全排除相邻采样片段被分到不同集合的相关性风险。这属于数据集本身的限制，最终报告必须明确说明。
