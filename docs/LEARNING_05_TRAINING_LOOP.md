# 学习 05：模型到底是怎么“学会”的

## 一轮训练做五件事

1. `DataLoader` 取出一批信号和正确标签。
2. 模型前向传播，输出每条信号的 `logits`。
3. `CrossEntropyLoss` 比较 logits 和正确标签，得到损失。
4. `loss.backward()` 计算每个参数应该往哪个方向调整。
5. `optimizer.step()` 真正更新参数。

这五步会对一个训练集中的所有批次重复一次，这叫一个 `epoch`。

## 优化器和学习率

- 优化器负责按照梯度更新参数。本阶段使用 `Adam`。
- 学习率决定每次更新迈多大一步。过大可能错过合适位置，过小则学习很慢。
- 本阶段的 `0.003` 只是合成数据链路验证参数，不是 RadioML 的最终最优参数。

## 训练和验证为什么分开

- 训练集参与参数更新。
- 验证集不更新参数，只检查模型对未参与本轮学习的数据表现如何。
- 如果只看训练准确率，模型可能只是记住训练样本，不能证明泛化能力。

## 本阶段结果能说明什么

合成 BPSK/QPSK 数据只用于确认：数据批次、模型、损失函数、反向传播和优化器能形成完整闭环。即使验证准确率很高，也不能写成 RadioML 或真实无线信道上的模型准确率。
