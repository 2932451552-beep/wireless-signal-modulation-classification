# 学习 11：第一次完整基线为什么要冻结配置

完整基线的作用是建立一个可重复、可比较的起点。不能训练过程中看到结果不满意就临时改学习率、轮数或数据，否则最终无法判断变化来自模型，还是来自实验规则改变。

第一版配置固定为：

- 模型：当前小型1D CNN；
- 训练集：154,000条；
- 验证集：33,000条；
- 测试集：33,000条，继续封存；
- Batch size：训练256，验证512；
- 优化器：Adam；
- 学习率：0.001；
- 最大轮数：20；
- Early stopping patience：4；
- 随机种子：20260812；
- 最小验证损失改善：0.0001。

每次实验使用新的输出目录，不能覆盖已有结果。产物包括最佳模型检查点和JSON记录，JSON保存配置、数据哈希、训练历史、验证指标、混淆矩阵、按SNR准确率和运行环境。

第一次完整训练仍只查看验证集。只有基线和后续改进方案确定后，才会启封测试集做最终验收。
