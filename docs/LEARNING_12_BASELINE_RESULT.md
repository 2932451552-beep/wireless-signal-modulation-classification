# 学习 12：第一次完整基线结果

## 实验范围

第一次完整基线严格使用固定配置：154,000条训练样本、33,000条验证样本、20轮训练。33,000条测试样本继续封存，没有用于训练、早停、模型选择或指标计算。

产物保留最佳模型检查点和JSON实验记录。模型检查点SHA-256为：

```text
007865c148f8045c9901b88a16693c173a9101434eb7d2265a494844e919df47
```

## 验证集结果

- 最佳轮次：20
- Validation Accuracy：40.89%
- Macro F1：38.20%
- 训练及验证耗时：约63秒

模型在低SNR时接近11分类随机猜测水平，随SNR提高而明显改善：-20 dB约9.03%，0 dB约56.00%，14 dB约60.85%。这说明噪声强度确实是识别性能的重要条件。

## 不能只看40.89%

Macro F1低于Accuracy，说明各类别表现不均衡。验证结果中：

- GFSK、PAM4、CPFSK的F1相对较高；
- QAM16的Recall约1.63%，大量被识别成QAM64；
- 模型还经常把多种类别识别成AM-SSB；
- WBFM和8PSK的Recall也较低。

因此该基线的价值是建立真实、可复现的起点，而不是证明当前模型已经足够好。

## 下一步如何改进

当前SimpleCNN使用全局平均池化，可能丢失对不同调制方式有用的时序结构。下一步应先基于验证集做一次受控架构改进，只改变一个主要因素，再与本基线按相同划分和指标比较。

测试集仍不能启封。只有基线和候选改进方案确定后，才能用测试集进行一次最终验收。
